# 🛒 E-commerce Sales Dashboard 📊

## 📌 Project Overview

This project analyzes e-commerce sales data using **Microsoft Power BI**. The interactive dashboard helps track sales, profit, quantity sold, and business performance through charts and visualizations.

## 🎯 Objectives

* 📈 Analyze overall sales performance.
* 💰 Track total sales and profit.
* 📦 Monitor product quantities sold.
* 👥 Understand customer purchasing patterns.
* 📊 Identify sales trends and business insights.

## 🛠️ Tools Used

* 📊 **Power BI** – Dashboard creation and data visualization.
* 📁 **Data Analysis** – Analyze sales data and identify trends.

## ✨ Key Features

* 📈 Interactive charts and graphs.
* 💰 Sales and profit analysis.
* 📦 Product performance tracking.
* 🔍 Easy-to-understand visual reports.
* 📊 Business performance monitoring.

## 💡 Key Benefits

* Helps businesses understand sales performance.
* Identifies profitable products and sales trends.
* Supports data-driven decision-making.

## 🚀 How to Use

1. 📥 Download the `.pbix` file from this repository.
2. 💻 Open it using Microsoft Power BI Desktop.
3. 📊 Explore the dashboard
